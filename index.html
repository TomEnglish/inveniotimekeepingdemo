Timesheet approvals without the email chains.

Multi-node approval routing, field claim/release, badge reconciliation, and a payroll-ready labor export — on the same data, audit-tracked at every step. Built for industrial crews where one timesheet might cross three subcontractors, two approvers, and a payroll deadline.

What it does

Setup

Multi-node approval flows, project + area trees, employee roster with sub-history spans, task codes, CWPs, FCOs, subcontractors, role assignments at silo and project scope.

Submission

Staff weekly grid (ST + OT, Mon–Sun, area / task / CWP / FCO per row). Field shells with claim/release for foremen. Recall while in flight. Resubmit only the rejected lines.

Approval & reconciliation

Multi-node routing with optimistic-concurrency conflict detection. Admin reassign and override. Badge reconciliation runs alongside the main flow with explicit cascade on conflict.

Export & audit

CSV / XLSX labor export ready for payroll. Append-only approval-actions log with comment + actor + timestamp. Tenant-scoped notifications and stall detection out of the box.

The pages

A walkthrough of every screen in the app.

Overview

Dashboard

Land here after sign-in. Five live KPI tiles — pending approvals, submitted this week, approved this week, open field shells, drafts not yet submitted — and a per-row pending-approvals list with one-click Approve, Reject (with comment), or Reassign. Optimistic-concurrency conflicts surface as an info banner so two approvers acting at once never corrupt the run.

Setup

Approval Flow Editor

Up to five sequential nodes per flow. Each node accepts approvers as specific users, by silo role (foreman, timekeeper_admin), or by project role — so structural changes to the org propagate without re-authoring flows. Reorder nodes with up/down arrows; partial unique constraints keep approver lists clean per branch.

Setup

Projects & Areas

Tenant-scoped project list with the area subtable inline. Projects show attached approval flows and active subcontractors. Activation is a chip — deactivate to hide from new submissions while preserving historical attribution.

Setup

Employees

Roster across all subcontractors. Subcontractor changes don't overwrite — they open a new history span and close the previous one, so payroll knows exactly which sub the hours belong to in any given week. Soft-delete preserves attribution on past timesheets.

Setup

Codes & Subcontractors

One screen, four tabs — task codes, CWPs (Construction Work Packages), FCOs (Field Change Orders), and subcontractors. Each tab is a flat tenant-scoped list with add / edit / soft-delete. External-id columns keep round-trips with field-tracking systems clean.

Submission

Staff Timesheets

Weekly Mon–Sun grid. Rows are (area, task code, CWP, FCO) tuples, cells are ST + OT with optional per-cell comments. Save does a true diff-sync on the line set — no full-table rewrites. Recall while in review pulls the timesheet back to draft so you can edit and resubmit.

Submission

Field Timesheets

Three sections — open shells (admin-created, awaiting a claimer), timesheets you've claimed, and your past submissions. Claiming a shell assigns it to you and flips it to draft. Release puts it back. The crew grid only shows employees on the claimed sub, so foremen can't accidentally book hours to the wrong company.

Approval

Manage Timesheets (Admin)

Tenant-wide list with combinable filters — kind (staff or field), status, project, subcontractor, date range. Click into any row to land in the same editor the submitter used, with admin override actions exposed.

Reconciliation

Badge Overrides

When timesheet hours don't match badge readings, an override opens its own approval run — parallel to the main timesheet flow, never blocking it. Resolution is canonical (timesheet wins or badge wins) with required reason. Badge-canonical resolutions cascade: open parents flip to rejected with HOURS_RECONCILED_TO_BADGE; already-approved parents generate an audit event for tenant admins.

Reporting

Labor Export

CSV or XLSX. Date range, status filter (default: submitted, in review, approved), project + subcontractor narrowing. Each line expands into ST and OT rows with full code context — area, task, CWP, FCO, sub, employee. XLSX adds a Summary by Project sheet for quick payroll review.
